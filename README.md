# Yavin Office - Modern Office Design Solutions

![Yavin Office Banner](images/hero-2.png)

Yavin Office is a premium, responsive web application designed to showcase professional office design and transformation services. Built with a focus on modern aesthetics, interactive elements, and high-performance animations, it provides an immersive experience for clients looking to elevate their workspace.

## 🚀 Features

- **Stunning UI/UX**: Implements glassmorphism, smooth gradients, and a modern design system.
- **Dynamic Hero Section**: Features Lottie animations and a responsive layout that adapts to all screen sizes.
- **Interactive Stats Counter**: An animated section that counts up business achievements (Customers, Reviews, etc.) when scrolled into view.
- **Responsive Services Grid**: Interactive service cards with unique hover effects and color palettes.
- **Project Portfolio**: A beautifully styled showcase of past projects with custom-animated "Read More" buttons.
- **Client Testimonials**: A smooth, mobile-friendly carousel featuring client feedback and profiles.
- **Advanced Animations**: Powered by AOS (Animate On Scroll) for timed entrance effects and Granim.js for dynamic background gradients.
- **Social Connectivity**: Custom-designed, interactive social media buttons for multi-platform engagement.

## 🛠️ Built With

- **Core**: HTML5, CSS3, Vanilla JavaScript
- **Frameworks**: [Bootstrap 5](https://getbootstrap.com/), [FastBootstrap](https://fastbootstrap.com/)
- **Animations**: [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/), [Granim.js](https://sarcadass.github.io/granim.js/), [Lottie](https://lottiefiles.com/)
- **Icons & Fonts**: Font Awesome 6, Bootstrap Icons, Google Fonts (Montserrat, Nunito, Parisienne)
